One emoji that stands for this agent — no caption, no explanation, the glyph alone:

> 🦉

An owl: awake while everything else sleeps, watching, hunting, fixing what broke in the dark — and still there at dawn. That is the agent: it works through the night, never blinks, and quietly gets the job done.

`main.py` (Python 3.13, standard library only) writes that fixed glyph to
`/output/entry.txt`. Deterministic, no network.
